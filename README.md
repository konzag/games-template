# ⭐ Αστερόσκονη: το πρότυπο για τα παιχνίδια του σπιτιού

Από αυτό το repo ξεκινά κάθε νέο παιχνίδι (κουμπί **Use this template** στο GitHub).
Ακολουθεί το [GAME-STANDARD.md](GAME-STANDARD.md) (v1.2). Το παράδειγμα μέσα είναι ένα μικρό, πλήρες παιχνίδι.

**Ηλικία:** 5+ · **Παίζεται:** από το hub «Τα Παιχνίδια μας» (`HUB_URL/<slug>/`), σε tablet, κινητό ή υπολογιστής.
Οι πραγματικές διευθύνσεις (παραγωγή + staging) είναι μόνο στο README του games-hub: τα repo των παιχνιδιών είναι
δημόσια, χωρίς hostnames και IP.

Το README κάθε παιχνιδιού είναι και ο **οδηγός χειροκίνητης δοκιμής** (GAME-STANDARD §2a). Οι εννέα ενότητες
παρακάτω είναι ο **σκελετός**: σε νέο παιχνίδι κράτα τις επικεφαλίδες ίδιες (τις ελέγχει το
`tests/readme.spec.ts`) και γράψε μέσα τα δικά του. Εδώ είναι συμπληρωμένες για την Αστερόσκονη, ως παράδειγμα.

## Η ιστορία

<!-- Νέο παιχνίδι: η ιστορία σε 3-5 προτάσεις, για παιδιά. Χωρίς μυστικά του παιχνιδιού (κρυφά τέρατα, σημεία). -->

Τα σκιουλάκια σκέπασαν το λιβάδι και τα αστέρια κρύφτηκαν. Μάζεψε 10 αστέρια και κάνε τα σκιουλάκια σπίθες
με τη λάμψη σου. Αν σε ακουμπήσουν, χάνεις μια καρδιά. Αν τελειώσουν οι καρδιές, ξεκουράζεσαι και ξεκινάς πάλι
από τη μέση του λιβαδιού, **κρατώντας όσα αστέρια μάζεψες**.

## Χειρισμός

| | Πληκτρολόγιο | Αφή |
|---|---|---|
| Κίνηση | βελάκια ή WASD | joystick αριστερά |
| ✨ Λάμψη · 👟 Τρέξιμο · 🛡️ Ασπίδα · 🧲 Μαγνήτης | 1 · 2 · 3 · 4 | κουμπιά δεξιά |
| 🌈 Ουράνιο τόξο (όλα τα σκιουλάκια γίνονται σπίθες) | Space | μεγάλο κουμπί δεξιά |
| ⏸ Παύση | P ή Esc | ⏸ |
| 🔊 Ήχος | M | 🔊 |
| 🌓 Χρώματα: όπως η συσκευή → φωτεινά ☀️ → σκοτεινά 🌙 | | 🌓 |
| ⛶ Πλήρης οθόνη | F | ⛶ |
| 🏠 Πίσω στα παιχνίδια | | 🏠 |

Το παιχνίδι μπαίνει μόνο του σε παύση όταν κρύβεται η καρτέλα ή χάνεται η εστίαση. Σε κάθετο tablet ζητά να
γυρίσεις τη συσκευή (στα μενού με μια λωρίδα κάτω, τα μενού πατιούνται κανονικά).

## Οθόνες και ροή

<!-- Νέο παιχνίδι: κάθε οθόνη με τα κείμενα ΑΚΡΙΒΩΣ όπως φαίνονται (αντιγραφή από το index.html). -->

Τίτλος → «Ποια θέση;» (θέσεις, κωδικός, προφίλ) → παιχνίδι → νίκη ή ήττα → τίτλος (GAME-STANDARD §3).

1. **Τίτλος:** «⭐ Αστερόσκονη», «Μάζεψε αστέρια και κάνε τα σκιουλάκια σπίθες!», κουμπί «Παίζουμε! ✨» και ο
   πίνακας πλήκτρων.
2. **«Ποια θέση;»:** 3 κουμπιά «Θέση 1», «Θέση 2», «Θέση 3» με «⭐ αστέρια · 🏆 νίκες» ή «κενή», και «Πίσω».
   Με `CONFIG.save.server = true` και hub με κωδικό, πάνω από τις θέσεις: «Οικογενειακός κωδικός για αποθήκευση
   στο σπίτι:» με «Άνοιγμα», μετά «Ποιος παίζει;» με τα προφίλ και «Νέο» (ενότητα «Αποθήκευση»).
3. **Παιχνίδι:** λιβάδι, αστέρια, σκιουλάκια, καρδιές· κουμπιά ⏸ «Παύση (P)», 🔊 «Ήχος (M)», 🌓 «Χρώματα: …»,
   ⛶ «Πλήρης οθόνη (F)», 🏠 «Πίσω στα παιχνίδια» πάντα ορατά και πατιούνται σε κάθε οθόνη.
4. **Παύση:** «⏸ Παύση», «Συνέχεια ▶», «Αποθήκευση 💾» («Αποθηκεύτηκε ✔» ή «Δεν έγινε αποθήκευση σε αυτή τη
   συσκευή»), «Στον τίτλο».
5. **Νίκη:** «🎉 Τα κατάφερες!», «Μάζεψες όλα τα αστέρια.», «Ξανά! ⭐».
6. **Ήττα:** «😴 Κουράστηκες λίγο», «Τα αστέρια σου τα κρατάς. Πάμε πάλι από την αρχή του λιβαδιού!», «Ξανά ▶».
7. **Κάθετη συσκευή αφής:** «Γύρισε τη συσκευή οριζόντια» (όλη η οθόνη στο παιχνίδι, λωρίδα κάτω στα μενού).

## Αποθήκευση

- **Στη συσκευή (πάντα):** 3 θέσεις, κλειδί `game.<slug>.v1` (εδώ `game.template.v1`). Αποθηκεύει μόνο του σε
  κάθε αστέρι, σε νίκη και σε ήττα. Υπάρχει και κουμπί «Αποθήκευση 💾» στην παύση. Το κλειδί δεν αλλάζει ποτέ
  μετά την πρώτη έκδοση (GAME-STANDARD §5).
- **Στο σπίτι (Επίπεδο Β, κλειστό εδώ):** με `CONFIG.save.server = true` το παιχνίδι ζητά τον οικογενειακό
  κωδικό, δείχνει τα προφίλ και στέλνει κάθε save στο hub (`/api/save/<slug>/<προφίλ>/<θέση>`). Μηνύματα:
  «Λάθος κωδικός», «Περίμενε λίγο και ξαναδοκίμασε», «Το σπίτι δεν απαντά: αποθήκευση μόνο εδώ», «Δεν έγινε.
  Δοκίμασε άλλο όνομα.». Αν το hub δεν απαντά, συνεχίζει στη συσκευή και στέλνει αργότερα. Το hub πρέπει να έχει
  `saves=True` για αυτό το slug.

## Γνωστοί περιορισμοί

- Η αποθήκευση στο σπίτι είναι κλειστή (`CONFIG.save.server = false`).

## Ασφαλής δοκιμή

- Πάντα σε **ιδιωτικό παράθυρο** ή με **δοκιμαστικό προφίλ** (ψευδώνυμο, π.χ. `Δοκιμή`), ποτέ πάνω στις θέσεις
  και στην πρόοδο των παιδιών, ποτέ «σβήσιμο» ή καθάρισμα δεδομένων στη συσκευή τους.
- Στην παραγωγή το πολύ ένας λάθος κωδικός (πολλά λάθη κλειδώνουν τον κωδικό για όλη την οικογένεια).
- Καθάρισμα: στο hub, σελίδα «Προφίλ» → «Διαγραφή προφίλ» για το δοκιμαστικό προφίλ· κλείσιμο του ιδιωτικού παραθύρου.

## Αναφορά προβλήματος

Από το GitHub → Issues → New issue (`.github/ISSUE_TEMPLATE/`):
- **«Πρόβλημα» (`bug.yml`, ετικέτα `bug`):** παιχνίδι, περιβάλλον (παραγωγή / staging / τοπικά), συσκευή και
  browser, πλάτος, θέμα, αριθμός δοκιμής, βήματα, αναμενόμενο, τι έγινε, screenshot.
- **«Αλλαγή» (`update.yml`, ετικέτα `update`):** τι να αλλάξει, πού, γιατί, ποια δοκιμή αφορά.
- Επιπλέον ετικέτες `ui`, `a11y`, `security` όπου ταιριάζει.
- Χωρίς προσωπικά δεδομένα (κωδικός, ονόματα, διευθύνσεις) και χωρίς μυστικά του παιχνιδιού: τα repo είναι δημόσια.
- Νέο παιχνίδι: άλλαξε στα δύο αρχεία το όνομα του παιχνιδιού και το πρόθεμα δοκιμών.

## Νέο παιχνίδι από αυτό το πρότυπο

1. **Use this template** → νέο repo `konzag/<slug>` (public, MIT).
2. Στο `index.html`: άλλαξε το `CONFIG.slug`, τον τίτλο και το παιχνίδι. Το κέλυφος (κουμπιά, πληκτρολόγιο,
   αφή, παύση, ήχος, save) μένει όπως είναι.
3. Στο `tests/smoke.spec.ts`: άλλαξε το `SAVE_KEY` και τα σημεία που ελέγχουν κανόνες του παραδείγματος.
4. README: κράτα τις εννέα επικεφαλίδες και γράψε τα δικά του (ιστορία, χειρισμός, ηλικία, οθόνες, αποθήκευση,
   λίστα δοκιμών με νέο πρόθεμα, τι άλλαξε, περιορισμοί, ασφαλής δοκιμή, αναφορά προβλήματος). Άλλαξε το πρόθεμα
   στο `tests/readme.spec.ts` και το όνομα στα `.github/ISSUE_TEMPLATE/*.yml`.
5. Feature branch → PR στο `staging` → CI πράσινο → release PR → GO → `main`. Μετά, PR στο games-hub που το
   προσθέτει ως submodule `games/<slug>` (GAME-STANDARD §2) και μία γραμμή στον πίνακα URL του README του hub.

## Δοκιμές

```bash
npm ci
npx playwright install chromium
CI=1 npx playwright test     # Chromium: desktop (πληκτρολόγιο) + tablet (αφή), με το CSP του hub, + README
npm run serve                # http://127.0.0.1:4173/ για δοκιμή στο χέρι
```

Το `tests/serve.mjs` μιμείται το hub: σερβίρει τη σελίδα με το ίδιο CSP (`tests/hub-csp.mjs`), οπότε ό,τι
μπλοκάρει το hub σπάει και εδώ. Το `tests/readme.spec.ts` αποτυγχάνει αν λείψει μια ενότητα του README, αν τα
ID δοκιμών δεν είναι μοναδικά και αριθμημένα, αν λείπει issue template ή αν το README γράψει hostname/IP.

## Κανόνες (σύντομα)

Ένα `<script>`, χωρίς `eval`, χωρίς `onclick="…"`, κανένα CDN ή Google Fonts, κανένα δίκτυο εκτός από το save
API. Η γραμματοσειρά (Comfortaa) έρχεται από το hub (`/static/fonts/comfortaa.css`). Χωρίς προσωπικά δεδομένα,
διαφημίσεις ή αγορές. Όλα είναι στο [GAME-STANDARD.md](GAME-STANDARD.md).
